# LearningGit3RemoteRepo

This is the 3rd repo created in the course of learning Git. The purpose of this setup is to simulate a real-world scenario where two developers work on the same codebase, encounter a merge conflict, and then how to go about resolving it.

One remote repo created on GitHub, two local repos created on PC, linked the two local repos to the single remote repo on GitHub... testing begin... making changes to the same line of code...

While simulating a merge conflict, Coder1 and Coder2 were used to represent two different users working on the same project/repo, and the names of their respective local repos were named after them accordingly. Both local repository cloned from the same remote repository on GitHub.

Coder1 might make changes to a file and push those changes to the remote repository. Meanwhile, Coder2 might also make changes to the same file and try to push their changes. This leads to a merge conflict, which needs to be resolved by merging the changes from both coders in a way that maintains the integrity of the code.

By practicing with Coder1 and Coder2, I learnt how to effectively manage and resolve merge conflicts, ensuring smooth collaboration in team projects.
