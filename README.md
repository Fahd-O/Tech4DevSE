# Tech4Dev Software Engineering Course Repository

## Overview

This repository consolidates all course modules and projects from the **Tech4Dev Software Engineering Program**. The program aims to empower Africans by providing access to decent work and entrepreneurship opportunities through **digital skills empowerment** and advocacy. The initiative is dedicated to scaling access to sustainable tech careers and transforming how talent connects with opportunity, ensuring economic prosperity for young Africans and marginalized groups.

## Modules and Technologies Covered

The course included six modules covering foundational and advanced topics in software engineering. Below is a summary of each module and its focus:

1. **Git**

   - Version control and collaboration basics.
   - Learning how to create, clone, push, and manage repositories.

2. **Backend**

   - Introduction to backend development.
   - Implemented a **Shopping Wishlist API Project**.

3. **BootStrap**

   - Building responsive designs using BootStrap.
   - Highlight: **SkatingSite Project** showcasing modern UI techniques.

4. **HTML-CSS-JS**

   - Core front-end development skills.
   - Highlight: **Landing Page with Login Section** demonstrating basic interactivity.

5. **React**

   - Building dynamic and component-based front-end applications.

6. **SASS**

   - Introduction to the SASS preprocessor for efficient and maintainable CSS.
   - Highlight: **Landing Page Starter Project**.
